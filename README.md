# مجله فناوری | IT Magazine

مجله فارسی (راست‌به‌چپ) برای مقاله، خبر و آموزش در حوزه‌های هوش مصنوعی، برنامه‌نویسی، توسعه وب، امنیت، Cloud/DevOps و سایر موضوعات IT.

**استک:** Python · Django 5.2 · Django REST Framework · PostgreSQL · Redis · Tailwind CSS · HTMX · Vanilla JS · django-allauth · Claude API

## امکانات

### محتوا
- **۱۳ دسته‌بندی** و **۱۱ نوع محتوا:** مقاله، خبر، آموزش، بررسی، ابزار AI، پروژه Open Source، مقاله علمی، مصاحبه، ویدئو، پادکست، AI Daily
- **صفحه مقاله:** فهرست مطالب خودکار، رنگ‌آمیزی کد با دکمه کپی، زمان مطالعه، تاریخ شمسی، نوار پیشرفت، تگ‌ها، مطالب مرتبط، اشتراک‌گذاری
- **ویدئو و پادکست:** لینک یوتیوب/آپارات یا **آپلود فایل** (mp4/webm، mp3/m4a/ogg)، مدت زمان، و **فید پادکست** با enclosure در `/rss/podcast/` برای اپ‌های پادکست
- **مصاحبه:** مشخصات مصاحبه‌شونده (نام، سمت، عکس) و بخش **پرسش و پاسخ** که در پنل به‌صورت inline وارد می‌شود
- **تصاویر:** کتابخانه تصاویر، آپلود از داخل ویرایشگر (دکمه، paste یا drag & drop)، کوچک‌سازی خودکار تصاویر بزرگ و حذف متادیتا، و ساخت **نسخه‌های WebP کاور** (480/960/1440) با `srcset`
- **AI Daily:** شماره‌گذاری خودکار و سه بخش «چرا مهم است؟ / چه کاربردی دارد؟ / تأثیر روی توسعه‌دهندگان»

### هوش مصنوعی
- **تولید خودکار AI Daily با Claude:** خبرهای منابع RSS (قابل تعریف در پنل) خوانده می‌شود، Claude مهم‌ترین خبر را انتخاب و به فارسی می‌نویسد (خروجی ساختاریافته). مطلب به‌صورت «در انتظار بررسی» ذخیره می‌شود (یا در صورت فعال بودن در تنظیمات، مستقیم منتشر می‌شود). منابعی که قبلاً پوشش داده شده‌اند تکرار نمی‌شوند.
- **پیشنهاد مقاله:** مدل TF-IDF روی عنوان، تگ‌ها، دسته‌بندی و متن؛ «مطالب مرتبط» در هر مقاله و **«پیشنهاد برای شما»** بر اساس مطالعه، لایک، ذخیره و موضوعات دنبال‌شده (صفحه اصلی، پروفایل و `/for-you/`)
- **جستجوی هوشمند:** نرمال‌سازی فارسی (ی/ک عربی، نیم‌فاصله، اعداد فارسی)، **مترادف‌های فارسی/انگلیسی** («پایتون» ⇄ Python، «هوش مصنوعی» ⇄ AI و...)، مرتب‌سازی بر اساس ارتباط، **اصلاح غلط تایپی** («pyton» ← python)، شباهت trigram در PostgreSQL، و پیشنهاد زنده در هدر

### کاربران
- ثبت‌نام/ورود با نام کاربری یا ایمیل، **تأیید ایمیل**، **بازیابی و تغییر رمز**، **ورود با گوگل و گیت‌هاب** (django-allauth)
- پروفایل، ذخیره، لایک، دنبال کردن موضوعات، فید شخصی، تاریخچه مطالعه
- **دیدگاه:** پاسخ، **ویرایش و حذف** توسط نویسنده، و ضد اسپم: honeypot، محدودیت تعداد ارسال، الزام ایمیل تأییدشده، نگه‌داشتن دیدگاه‌های پرلینک یا دارای کلمات ممنوع برای تأیید، و حالت تأیید دستی
- **اعلان‌ها:** زنگوله اعلان برای مطلب جدید در موضوعات دنبال‌شده و پاسخ به دیدگاه، به‌علاوه ایمیل (قابل خاموش کردن)
- **خبرنامه:** عضویت با تأیید دومرحله‌ای، AI Daily روزانه، خلاصه هفتگی، لینک لغو اشتراک و هدر `List-Unsubscribe`

### پنل مدیریت
- **داشبورد:** آمار مطالب، بازدید ۷ روز، کاربران جدید، مشترکین، دیدگاه‌های در انتظار، نمودار بازدید روزانه، پربازدیدترین‌ها، صف بررسی و انتشار زمان‌بندی‌شده
- **ویرایشگر Markdown** با نوار ابزار، میانبرها و **پیش‌نمایش زنده**
- **نقش‌ها:** «نویسندگان» فقط مطالب خودشان را می‌بینند و برای بررسی می‌فرستند؛ «سردبیران» منتشر و ویژه می‌کنند (اکشن «تبدیل به نویسنده/سردبیر» در لیست کاربران)
- **انتشار زمان‌بندی‌شده** با تاریخ انتشار در آینده
- **تنظیمات سایت** از پنل: نام و توضیحات، تصویر OG، شبکه‌های اجتماعی، کد آنالیتیکس، تنظیمات دیدگاه، انتشار خودکار AI Daily
- مدیریت بنرها و تبلیغات (جایگاه و زمان‌بندی)، صفحات، تگ‌ها، دسته‌ها، مشترکین

### فنی
- **SEO:** عنوان/توضیحات SEO، Open Graph، JSON-LD، canonical، sitemap، robots، RSS
- **کش:** Redis (یا حافظه در توسعه)؛ نسخه‌بندی محتوا برای باطل‌سازی خودکار کش‌ها، کش HTML رندرشده مقالات
- **API:** `/api/articles/` (فیلترهای `q`، `category`، `type`، `tag`)، `/api/categories/`، `/api/tags/`
- تم تیره/روشن، واکنش‌گرا، **بدون وابستگی به CDN**
- Docker، Nginx + HTTPS (Let's Encrypt)، زمان‌بند داخلی، CI در GitHub Actions با PostgreSQL

## راه‌اندازی (توسعه)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_magazine --demo   # دسته‌بندی‌ها، صفحات، منابع خبری، نقش‌ها و مطالب نمونه
python manage.py createsuperuser
python manage.py runserver
```

بدون `DATABASE_URL` از SQLite و بدون `REDIS_URL` از کش حافظه استفاده می‌شود. ایمیل‌ها در حالت توسعه در کنسول چاپ می‌شوند.
برای PostgreSQL و Redis: `docker compose up --build`

## کارهای زمان‌بندی‌شده

یک پروسس جدا همه‌چیز را اجرا می‌کند (نیازی به cron یا Celery نیست):

```bash
python manage.py run_scheduler
```

| زمان (قابل تنظیم با env) | کار |
|---|---|
| هر دقیقه | اطلاع‌رسانی مطالب زمان‌بندی‌شده‌ای که منتشر شده‌اند |
| ۰۸:۰۰ (`AI_DAILY_GENERATE_AT`) | ساخت AI Daily با Claude (اگر `ANTHROPIC_API_KEY` تنظیم باشد) |
| ۰۹:۰۰ (`AI_DAILY_SEND_AT`) | ارسال آخرین AI Daily منتشرشده به مشترکین |
| جمعه ۱۰:۰۰ (`WEEKLY_DIGEST_AT`) | ارسال خلاصه هفتگی |

هر کار را دستی هم می‌توانید اجرا کنید:

```bash
python manage.py generate_ai_daily [--author USERNAME] [--force]
python manage.py send_newsletter ai_daily|weekly
python manage.py dispatch_notifications
```

## AI Daily با Claude

1. `ANTHROPIC_API_KEY` را تنظیم کنید (مدل پیش‌فرض `claude-opus-5`؛ با `ANTHROPIC_MODEL` قابل تغییر).
2. در پنل، **منابع خبری AI Daily** را بررسی/اضافه کنید (فید RSS یا Atom).
3. از اکشن «ساخت AI Daily امروز» در همان صفحه یا دستور `generate_ai_daily` استفاده کنید.
4. مطلب در صف «در انتظار بررسی» داشبورد ظاهر می‌شود؛ پس از ویرایش، منتشرش کنید.

درخواست‌ها از **server-side fallback** استفاده می‌کنند: اگر مدل اصلی به دلایل ایمنی درخواستی را رد کند، API خودکار روی مدل جایگزین تلاش می‌کند.

## ورود با گوگل / گیت‌هاب

یک OAuth App بسازید و `GITHUB_CLIENT_ID`/`GITHUB_CLIENT_SECRET` یا `GOOGLE_CLIENT_ID`/`GOOGLE_CLIENT_SECRET` را تنظیم کنید. آدرس callback:
`https://<domain>/accounts/github/login/callback/` و `https://<domain>/accounts/google/login/callback/`.
تا کلیدها تنظیم نشوند، دکمه‌ها نمایش داده نمی‌شوند.

## فرانت‌اند (Tailwind)

CSS ساخته‌شده در مخزن است. اگر کلاس‌های قالب‌ها را تغییر دادید:

```bash
npm install
npm run build       # vendor کردن HTMX و فونت + ساخت CSS
npm run watch:css   # حین توسعه
```

CI بررسی می‌کند که CSS کامیت‌شده به‌روز باشد.

## ساختار پروژه

| مسیر | توضیح |
|------|-------|
| `config/` | تنظیمات و URLها |
| `magazine/` | مطالب، دسته‌ها، تگ‌ها، AI Daily (و تولید خودکار)، جستجو، پیشنهاد، ویرایشگر، RSS، sitemap، API |
| `accounts/` | کاربر سفارشی، پروفایل، نقش‌های نویسنده/سردبیر |
| `interactions/` | لایک، ذخیره، دیدگاه (ضد اسپم)، دنبال کردن موضوع، تاریخچه |
| `newsletter/` | خبرنامه، اعلان‌ها، زمان‌بند |
| `core/` | تنظیمات سایت، صفحات، بنرها، کش، داشبورد |
| `templates/`, `assets/`, `static/` | قالب‌ها، سورس Tailwind، فایل‌های استاتیک |
| `deploy/` | پیکربندی Nginx و اسکریپت HTTPS |
